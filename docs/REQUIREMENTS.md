# MyPage 需求文档

> 版本：v2.0（v1.0 基础上修订运行形态）
> 日期：2026-08-25
> 状态：已确认（v2.0 运行形态变更对齐稿，功能需求沿用 v1.0）

## 1. 项目概述

纯个人使用的本地启动器。双击 Ctrl（默认，可改）随时呼出主窗口：

- 跳转到自己收藏的网页
- 一键启动本机软件
- 打开收藏的本机文件夹 / 文件（调起系统默认程序）

本质是一个 Electron 桌面应用：主进程常驻系统托盘、监听全局热键，业务逻辑（SQLite + 处理器表）跑在主进程内，界面跑在渲染进程，两者经类型化 IPC 通信，**不开放任何 TCP 端口**。v1 的"浏览器首页"模式已移除；v2.1 起弃用 v2.0 过渡期的 Hono 假 HTTP 层，改为标准 `ipcMain.handle` 处理器表。

**单机、单用户、无鉴权、无同步。**

## 2. 范围

### 2.1 v1 做什么

| 模块 | 内容 |
| --- | --- |
| 网页收藏 | 手动增删改、分组、拖拽排序；favicon 自动抓取并本地缓存 |
| 书签导入 | 一次性导入 Chrome 导出的书签 HTML 文件 |
| 应用启动 | 手动添加 exe / 快捷方式（支持启动参数）；Windows 下提供开始菜单/桌面快捷方式选择器 |
| 文件/文件夹导航 | 收藏常用文件夹/文件，点击用系统默认方式打开 |
| 统一搜索 | 顶部搜索框实时过滤所有已收藏条目，回车打开首个结果 |
| 页面交互 | 经典导航页布局（分组卡片网格）+ 编辑模式 + 右键菜单 + 轻量设置页；中英双语界面 |
| 常驻运行 | Electron 托盘常驻；双击 Ctrl 全局热键呼出/隐藏主窗口；开机自启（设置页可控安装/卸载） |

### 2.2 v1 不做（非目标）

1. 全盘文件搜索 / 文件内容搜索
2. 文件页内预览（图片/文本等）
3. 文件夹页内逐层浏览（v1.1 候选）
4. 多设备同步、远程访问、用户认证
5. 使用频率统计与自动排序
6. 浏览器书签实时双向同步（仅一次性导入）
7. 系统级操作（关机/休眠/音量等）
8. UWP 应用与 URL 协议启动（`steam://` 等，v1.1 候选）

## 3. 功能需求

### 3.1 网页收藏

- 条目字段：标题、URL、所属分组、图标、排序位。
- 分组：可增删改名，分组内条目与分组本身均可拖拽排序。
- 图标策略：书签条目行内联 16px favicon。优先直连目标站点自身 favicon（兼顾国内网络可达性），失败走可配置镜像服务（`settings.favicon_mirror`，默认 DuckDuckGo，国内可能不可达），再失败**不显示图标退回纯文字行**（终端风定稿后替代原“首字母色块”方案）；成功图标缓存到本地数据目录（含失败负缓存），离线可显示。

### 3.2 书签导入

- 入口在设置页，选择 Chrome「书签管理器 → 导出书签」生成的 HTML 文件（Netscape 书签格式）。
- 导入时保留原文件夹结构映射为分组，重名分组合并。
- 仅一次性导入，不做后续同步；可重复执行（按 URL 去重）。

### 3.3 应用启动

- 手动添加：填写 exe 或快捷方式路径，可选启动参数、自定义显示名与图标。
- 辅助选择器（**v1 仅 Windows**）：扫描开始菜单与桌面快捷方式，列表供勾选添加；macOS / Linux 用户手动填路径，扫描器留待后续版本。
- 点击条目即启动；路径失效时给出明确错误提示（含失效路径），不静默失败。

### 3.4 本地文件/文件夹快捷方式

- 收藏任意文件夹或文件路径，支持归入分组、排序，与网页收藏同一套交互。
- 点击行为：文件夹 → 系统文件管理器（Explorer / Finder / 文件管理器）；文件 → 系统默认关联程序。
- 不做页内浏览，不在页面内展示文件内容。

### 3.5 统一搜索

- 顶部搜索框，过滤范围 = 全部已收藏条目（网页 + 应用 + 文件），匹配标题（v1 不做 URL / 路径全文匹配之外的能力）。
- 键盘交互：页面加载自动聚焦；输入即时过滤；`Enter` 打开首个结果；`Esc` 清空；`/` 随时重新聚焦。
- 搜索是过滤器，不是独立页面：无输入时完整展示分组网格。

### 3.6 页面布局与交互

- 布局：经典导航页——顶部搜索框，下方分组卡片网格铺开。
- 条目模型统一：一个分组内可混放网页/应用/文件条目，用类型角标区分（此为默认决定，见 §9）。
- 编辑模式：显式开关，进入后卡片可增删改、拖拽排序（条目与分组均支持），退出即恢复使用态。
- 右键菜单：随时对单个条目/分组做打开、编辑、删除等快捷操作。
- 设置页（轻量）：书签导入、自启开关、主题切换、语言切换。
- 视觉基调：终端风（原型 C 定稿，配色选「纸白」）——提示符即搜索框、条目即命令、底部 tmux 式状态栏；等宽字体为全站气质。
- 多语言：v1 提供中文 / 英文两套界面文案。首次访问按浏览器语言确定默认值（zh 系→中文，其余→英文），之后以用户在设置页的选择为准并持久化。
- 主题：深色 / 浅色跟随系统明暗自动切换，支持手动指定并持久化。

### 3.7 常驻、呼出与自启（v2.0 修订）

- **托盘常驻**：应用启动即在系统托盘显示图标，无主窗口自动弹出。
- **全局热键**：默认**双击 Ctrl**（300ms 内两次按下）切换主窗口显隐；呼出时恢复上次窗口状态（尺寸/位置/是否最大化）并聚焦。热键可在设置页从**预设列表**中选择（双击 Ctrl / 双击 Alt / 双击 Shift / Alt+Space 等常用组合），注册冲突时给出明确提示。双击类检测由低级键盘钩子（uiohook-napi）实现。
- **窗口行为**：常规系统边框（最大化/最小化/关闭按钮）；失焦不隐藏、Esc 不隐藏；**点关闭按钮 = 隐藏窗口**（程序继续常驻）；点最小化 = 正常最小化到任务栏。窗口记住上次位置/尺寸/最大化状态，首次启动默认约 1000×700 居中。
- **托盘交互**：左键单击 = 切换主窗口显隐（与热键等效）；右键菜单：显示主窗口 / 设置 / 退出。**退出程序唯一入口是托盘菜单**。
- **自启**：设置页开关控制，经 `app.setLoginItemSettings` 安装/卸载（Windows 写注册表 Run 项，macOS / Linux 由 Electron 对应机制处理）。设置页提示：程序目录被移动后自启项失效，需重新开启。
- v1 遗留的旧自启项（注册表 Run + VBS 启动器）由独立清理脚本一次性移除，不写入程序。

## 4. 非功能需求

### 4.1 安全边界（v2.0 修订）

v1 以网页形态暴露在浏览器中，需四道防线（回环监听、Host/Origin 校验、操作令牌）防恶意网页向本机服务发请求。v2 移除 TCP 监听后，本机任意网页已无法触达业务逻辑，原防线整体退役，安全边界改为进程边界：

1. **主进程不监听任何 TCP 端口**，业务逻辑仅经 IPC 暴露给自家渲染进程。
2. **渲染进程不开 `nodeIntegration`**，仅通过 preload 暴露的白名单桥接接口（发起 RPC 请求、少数窗口操作）与主进程通信。
3. 渲染进程加载本地构建产物（`app://` 自定义协议或等价机制），不加载任何远程内容。

### 4.2 跨平台

- **核心功能**（收藏、搜索、启动、打开文件、存储、自启）在 Windows / macOS / Linux 均可用。
- **平台附加件**（快捷方式扫描选择器）v1 仅实现 Windows。
- 开发与日常验证主力平台：Windows；macOS / Linux 保证代码级兼容与核心路径正确。

### 4.3 工程质量（项目约束）

本项目同时是 TypeScript 学习项目，因此：

- **注释**：必要处加中文注释，重点解释「为什么」与类型设计意图（泛型参数、类型收窄、判别联合等），不写复述代码的废话注释。
- **可读性优先**：命名直白、逻辑平铺，宁可代码长一点也要一眼读懂。
- **禁止过度设计**：不预留用不到的抽象层、插件化、配置化；单仓库单 package；能十行解决不写一百行。
- **禁止炫技**：不使用无必要的花哨语法与间接层。

## 5. 技术选型

| 层 | 选择 | 备注 |
| --- | --- | --- |
| 桌面壳 | Electron | 主进程承载业务逻辑与托盘/热键/窗口；渲染进程承载现有 React 界面 |
| 全局热键 | uiohook-napi（libuiohook 绑定） | 低级键盘钩子实现双击检测；组合键类热键用 Electron `globalShortcut` |
| 前后端通信 | 类型化 IPC（`server/api.ts`） | MpApi 接口是前后端唯一契约：主进程处理器表与渲染进程 client 均按它实现，签名漂移编译期报错；可预期错误走 `ApiResult` 判别联合而非状态码 |
| 前端框架 | React + TypeScript + Vite | |
| UI 组件 | shadcn/ui（Radix 无头组件 + Tailwind CSS） | 视觉完全自有，深浅色 CSS 变量原生支持 |
| 视觉方向 | 终端风格「纸白」：等宽排版、`$` 提示符式搜索、面板分组、tmux 式状态栏 | 参照 `prototypes/c-terminal-colors.html` 的 paper 主题。深色态 = 暖白磷光于暖黑底（#EDE9DB / #0A0A08）+ 微弱 CRT 质感；浅色态 = 纸面终端（纸色底墨色字），CRT 质感仅在深色态保留。字体栈 Cascadia Mono / Consolas / Sarasa Mono SC |
| 图标 / 拖拽 / 提示 | lucide-react / dnd-kit / sonner | |
| 界面多语言 | 自研轻量 i18n：扁平 key + 类型安全字典 + React Context | 本项目文案量小（百条级），自研约几十行且 key 类型直达；语言需求变复杂（更多语种、复数、格式化）再换 react-i18next |
| 后端逻辑 | `server/` 处理器表 + zod | v1/v2.0 用 Hono；v2.1 起为纯函数处理器，入口 zod 校验，无框架依赖 |
| 数据库 | SQLite + better-sqlite3 | 同步 API，三平台均有预编译；Electron 下需匹配其 ABI（预编译或 electron-rebuild） |
| 打开文件/文件夹 | `open` 库 | 内部对应 Explorer / Finder / xdg-open |
| 打包分发 | electron-builder，Windows 目录版（v2.1 起 `dir` 目标，不做单文件/安装器） | 数据目录沿用各平台用户数据目录下 `MyPage/`，v1 数据无缝沿用 |
| 包管理 | pnpm | Node v24 运行时 |

单仓库单 package：Electron 主进程同时承担 HTTP 业务（进程内）与系统集成（托盘/热键/自启/窗口），渲染进程只跑界面。数据文件存放于各平台用户数据目录（Windows `%APPDATA%`、mac `~/Library/Application Support`、linux `~/.config`）下的 `MyPage/`。

## 6. 数据模型概要

```text
groups    id, name, position
items     id, group_id, kind('bookmark'|'app'|'file'),
          title, target(url 或 本机路径), args(app 专用, 可空),
          icon(缓存文件名或空=首字母色块), position
settings  key, value        -- 主题、语言、自启状态等
```

条目统一进 `items` 表以 `kind` 区分，是最简模型；分组可混放不同 kind 的条目。

## 8. 风险与对策

| 风险 | 对策 |
| --- | --- |
| better-sqlite3 预编译与 Electron ABI 不匹配 | 优先用其 Electron 预编译；缺失时 electron-rebuild 本机编译（需 VS Build Tools） |
| uiohook-napi 维护停滞或与新版 Electron 不兼容 | 钩子调用集中隔离在单一模块；备选 @jannchie/uiohook-napi 维护分支或退回预设组合键（`globalShortcut` 即可覆盖） |
| 程序目录被移动后自启失效 | 设置页开关旁明确提示；重新开启即修复 |
| 双击 Ctrl 与其他软件热键冲突（如改键为常见组合） | 注册失败给出明确提示，回退上一次可用热键 |
| favicon 抓取受国内网络限制 | 直连站点自身 favicon 优先 + 可配置兜底服务 + 首字母色块保底 |
| macOS / Linux 无真机验证 | 平台相关代码集中隔离在单一模块，核心路径保持跨平台写法 |

## 9. 已确认并实施的默认决定

1. **分组内可混放不同类型条目**（网页/应用/文件同组，类型角标区分）——已实施。
2. **搜索匹配范围**：标题与目标包含即命中（大小写不敏感）；拼音/首字母匹配未实施（v1.1 候选）。

## 10. v2.0 已确认的默认决定

1. **彻底移除 TCP 监听**：不用回环 HTTP 做内部管线，渲染进程经 IPC 桥接直连主进程 `app.fetch`；v1 四道防线随之退役。
2. **窗口形态**：带系统边框的常规窗口（非无边框调板），关闭 = 隐藏、最小化正常进任务栏、失焦/Esc 均不隐藏。
3. **热键可配置范围 = 预设列表**（双击 Ctrl / 双击 Alt / 双击 Shift / Alt+Space 等），不做自由录制。
4. **托盘左键单击 = 切换显隐**，与热键等效；退出程序唯一入口在托盘菜单。
5. **分发 = electron-builder 目录版**（v2.0 曾用便携版单 exe，v2.1 起改 `dir` 目标），不用安装器；数据目录与 v1 相同，无缝沿用。
6. **v1 自启清理 = 独立脚本**手动运行一次，不写入程序逻辑。

## 11. v2.2：三区工作区（内置工具 + 页内终端）（2026-08-26）

原分组网格改为 VS Code 式三区布局（原型见 `docs/layout-prototype.html`），已实施并实测通过。

### 11.1 布局与交互

1. **左：分组侧栏**——分组纵向堆叠，组头点击折叠/展开（搜索时强制展开并过滤），条目/分组拖拽排序与编辑模式语义不变；侧栏宽度可拖（190–480px）。
2. **右上：内置工具区**——动态 tab 集合；唯一入口是搜索行右侧「工具 ▾」下拉（● 已打开 / ○ 未打开）。tab 的 × 关闭即卸载组件（工具组件 `React.lazy` 懒加载，关闭即释放，重开回到初始态）；非活动工具 `display:none` 保活（切 tab 不丢草稿）。全部关闭后工具区自动消失，终端独占右列。
3. **右下：页内终端**——node-pty + xterm.js，多会话 tab（＋ 新建 / × 关闭并结束进程），高度可拖；窗口藏进托盘再呼出，会话与回滚内容保留；退出应用统一回收 shell 进程。默认 shell：pwsh → powershell → cmd（Windows）/ $SHELL → bash（类 Unix）。
4. **布局状态存渲染进程 localStorage**（侧栏宽、终端高、终端显隐、已开工具），与主题/语言同一策略。
5. 默认窗口 1180×760、最小 840×520；旧存档尺寸下限钳到 900×560。

### 11.2 初始工具集

json 格式化/压缩、二维码生成（qrcode 库，黑白固定配色保证扫码兼容）、条码/二维码识别（@zxing/library；拖入 / Ctrl+V 粘贴 / 选文件）。新工具 = `src/tools/` 下组件 + `registry.ts` 注册一行 + i18n 两键。
