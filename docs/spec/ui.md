# 界面与交互规格

长期规格，描述界面现在应该是什么样、为什么这样定。改界面行为时在同一次改动里更新这里；工作规则和命令见 [AGENTS.md](../../AGENTS.md)，内置工具见 [TOOL_SPEC.md](../../src/renderer/src/tools/TOOL_SPEC.md)。

主结构：顶栏（品牌、搜索、工作区工具栏、常驻按钮）+ 左侧栏（工作区块 + 快捷启动列表）+ 右侧停靠区。

## 视觉与主题

- 界面为 GaN.UI 中性灰体系：来源仓库 `D:\MyCode\GaN.UI`，源码基线 v1.5.4（提交 `0edf835`），组件复制于 `src/renderer/src/components/ui/`，令牌与材质全在 `src/renderer/src/index.css`。
- 深浅双主题：深色默认（冷调石墨），浅色为「薄雾」（淡蓝灰底，色系经上游承自 Darwin 取色）。强调色：深 `#0a84ff` / 浅 `#4f46e5`。
- 字体：Outfit（可变）+ IBM Plex Mono，woff2 内嵌于 `src/renderer/src/assets/fonts/`。**不引入 MiSans，不引入 Geist。**
- 主题唯一权威来源是 settings 表 `theme` 键（dark/light）：
  - 主进程开窗前直读，定窗口 `backgroundColor`。
  - 渲染端 `index.html` 内联脚本经 preload 的 sendSync 同步桥（`getThemeSync`）在首帧前给 `<html>` 套 `.dark` 类。
  - 切换入口只有设置里的分段控件（顶栏没有主题按钮），即点即换，并经 `mp:set-theme` 通知主进程更新窗口外观。

`components/ui/` 与上游支撑模块（`lib/platform|shortcut|density|scroll`、`hooks/use-overlay-density|use-size-token|use-virtual-rows`）保持上游原样（2 空格、无分号），`.prettierignore` 已排除，改它们等于放弃下次整文件 diff。这些文件注释里提到的 `docs/design.md` 指上游仓库的文档，不是本仓库的。

只复制用得到的组件。`attachment`、`disclosure-group`、`avatar`、`alert` 和 `skeleton` 没有放进本仓库，要用时再从上游取；对应的令牌还留在 `index.css`。

本地只有三处差异，别的都要么回上游、要么放业务层：

1. `lib/utils.ts` 用 `extendTailwindMerge` 把 `micro/caption/small/control/readout/display` 登记进 font-size 组（替代上游的 `cn` 包，未引入 cn 包）。
2. `index.css` 同时定义 `gan-drag`/`gan-no-drag` 与项目现有的 `app-drag`/`app-no-drag`。

## 窗口与顶栏

- 启动链上任何一步出错（开库、建表、迁移等）都弹错误框显示原因并退出，不留看不见的后台进程。
- 窗口**无边框**（`frame:false`），窗口边缘圆角与描边全归 OS，不自画。
- 拖拽区覆盖整个顶栏的品牌和空白区域；搜索框、工作区工具栏、按钮和弹出内容保留 `app-no-drag`，才能正常接收输入事件。
- 顶栏从左到右：品牌（图标 + 名称）、搜索框、空白、工作区工具栏、工具集菜单、钉住、置顶、设置。左侧栏常驻，不能隐藏。
- **品牌**：名称走 i18n `app.brand`，中英文都是 `Knock`，上下叠两行（11px 字、12px 行高，两行合计 24px，放得进 40px 顶栏）。
- **搜索框**：跟在品牌右边，间距 20px，不居中。期望宽 540px（也是最宽，不会再长）、最窄 260px，顶栏不够宽时它先缩，缩到最窄还不够才轮到工作区工具栏被挤窄。下拉面板与搜索框同宽。
- **空白**：搜索框与工具栏之间的弹性空白是拖窗口的地方；工具栏按内容宽度排，不撑满，所以空白不会被它吃掉。没有工具栏时（临时工作区、断线态）搜索框位置不变，右边整片是空白。
- 搜索候选只收全局条目，工作区条目只在工具栏出现；搜索框规则见下面「搜索框」。
- 钉住：失焦不自动隐藏，双击 Ctrl 不再收起，跨重启保持。按钮图标固定为图钉，不随状态换成划线款，是否钉住只靠按钮按下变色表示（提示文字仍在「钉住」和「取消钉住」间切换）。
- 置顶：钉住下的子状态，仅本次运行有效；未钉住时置顶按钮禁用。图标是「横线在上、箭头向上」（lucide 的 `ArrowUpToLine`）。

## 搜索框

规则对所有工具一样，不是便签专属（实现在 `components/SearchBox.tsx`）。

下拉分三块，各答一件事：

| 区 | 回答什么 | 内容 | 选中后 |
| --- | --- | --- | --- |
| 命中区 | 我想找什么 | 匹配的快捷启动条目 + **所有**匹配的内置工具（名称、id、别名、描述的包含匹配；条目在前、工具在后，最多 9 行） | 只打开，不带字 |
| 推荐区 | 这段字交给谁 | 吃文本的工具 + 勾了推荐的专家，恒在 | 带入文字 |
| 路径区 | 输入像本地绝对路径且存在时 | 文件：打开文件 + 前往所在目录；文件夹：前往 | 执行动作 |

- **条目怎么匹配**：所有条目按标题匹配；**只有目标是本机文件夹的条目，目标路径也参与匹配**（用路径找文件夹）。网址、应用、命令、文件的目标一律不参与，否则打 `com`、`exe` 之类会命中一大片。「是文件夹」沿用 `dirIds` 的运行时判定，判定结果回来之前，文件夹条目只按标题命中。
- **带入内容**：有复制内容（chip）带复制内容，否则带打的字。只有推荐区的行带字，命中区的行（包括便签、translate 这类吃文本的工具）只打开。
- **同一个工具可能出现两次**：命中区一行（只打开）、推荐区一行（带字），按想不想带字选。
- **推荐区永远显示**：基础顺序固定为便签、json、qrcode、files、translate，勾了推荐的专家排在后面。内容是链接或 JSON 时，qrcode 或 json 临时排到第一，其余相对顺序不变（打 JSON 时是 json、便签、qrcode、files、translate）。便签在 `TOOLS` 数组里排在最后，工具首页和工具集菜单的顺序不受影响，推荐区的顺序在 SearchBox 里单独定。
- **默认高亮与 Enter**：
  - 纯手打：路径区和命中区在上、推荐区沉底，Enter 落第一个路径/命中行；↓ 走到底进推荐区。
  - 手打但路径区、命中区都没东西：显示「（无匹配）」，**不预选任何行，Enter 什么都不做**，要带字先按 ↓ 选推荐行。手打的字不会悄悄进便签。
  - 有复制内容（chip）：从上到下是路径区、推荐区、命中区，高亮第一行。复制的不是路径时第一行就是推荐区第一行，Enter 直接注入，「复制 → 呼出 → Enter」的素材流不变；复制的是存在的本地路径时，第一行是路径区的「打开文件」或「前往文件夹」，Enter 直接打开，要带进便签等工具就按 ↓ 选推荐行。
- **路径区恒在最上**：不管是手打还是复制的内容，只要是存在的本地路径，路径区就排在所有区的最前面。
- 搜索框里粘贴图片不做处理。

## 左侧栏

与工具区直接相邻。自身不带右边线，和停靠区的分界靠底色深浅（见「停靠区 · 外观」）。

- **两种形态**：完整侧栏，和收成只有图标的窄条（图标条）。
  - **完整侧栏**：默认 246px，拖右边缘可改，最窄 200px、最宽为窗口宽度的 40%（窗口变窄时只夹住显示，不改已存的偏好）。
  - **图标条**：固定 52px，不能单独拖宽。
- **进出图标条只靠拖右边缘，没有按钮**：侧栏右缘被拖过 120px 就吸附成图标条，往右拖过 120px 就展开并跟着指针走（最窄仍是 200px），所以 52 到 200px 之间的宽度不会出现。吸附没有动画。常量在 `SidebarResizer.tsx`（`RAIL_WIDTH`、`COLLAPSE_THRESHOLD`）。
- **记忆**：存 localStorage，两个键：`mypage-sidebar-width` 是**最后一次完整侧栏的宽度**（收成图标条时不覆盖它），`mypage-sidebar-collapsed` 是是否图标条。重启后保持图标条；展开时回到最后的完整宽度。
- **双击右边缘**：完整侧栏里回默认 246px；图标条里展开到最后的完整宽度（不是 246）。收成图标条只靠拖，不靠双击。
- **图标条里的内容**（三个组件各自带 `collapsed` 属性）：
  - 两个标题行保持 32px，文字去掉，「＋」居中，新建入口不丢。
  - 工作区行：一个 28px 圆角方块（同色 12% 透明度的底，和当前行底色同一档）里写名字首字，当前行仍有四边描边和左边竖色条。窗口数不显示，悬停提示是「名字 · N 个窗口 · 文件夹」。
  - 快捷启动行：只剩居中的 18px 图标，行高 26px 不变；悬停提示改成「标题 + 目标」两行，从右侧弹出。键盘、右键菜单、点击防抖都不变。条目为空时不显示引导文字，只剩上面的「＋」。
  - 列表隐藏滚动条（10px 的滚动条会把图标挤偏），滚轮和触摸板照常能滚。
  - 读屏：行里没有文字了，所以工作区行和快捷启动行补 `aria-label`。
- **拖拽区不可见**：不画线、不画把手、悬停也不变色，只有鼠标移上去时光标变成左右箭头。实现是 `SidebarResizer`，贴着 aside 右边缘、跨两边各 2px（共 4px），用指针捕获，拖出窗口也不断。停靠区里的网页面板（`<webview>`）是独立的页面进程，指针拖进去事件就被网页接走、捕获也拦不住，所以拖拽期间另盖一层全透明的整窗遮罩，松手即撤。别给它加可见元素。

### 工作区块

在快捷启动列表上方，标题行带新建按钮。标题行与列表行同高，都是 32px 单行（标题行的 32px 含底边线）。

- **高度**：可拖拽并记住，默认 192px（六行）、最小一行、上限为侧栏高度的 70%，双击拖拽条复位，高度存 localStorage，超出就在区块内部滚动。
- **配色**：每行左侧一道竖色条。普通工作区默认按 id 取固定调色板，用户可在右键菜单「颜色」里从同一份调色板（十个色块）挑一个，选了之后存进库，「恢复默认」回到按 id 取色；自带的「临时工作区」取中性灰，不可改。当前行另铺同色低透明度底色，并套上下左右四边 1px 同色内描边。配色与描边强度只在 `lib/workspaceColor.ts` 和 index.css 的 `--ws-stroke` 令牌里定义。
- **行内容**：工作区名与该工作区停靠区里的窗口数（工具＋终端面板总数，悬停提示完整说法）。行悬停提示里带完整文件夹路径。
- **普通工作区**：创建时必须选一个现存文件夹；右键菜单为重命名/修改文件夹/颜色/删除。
- **临时工作区**：没有文件夹，不可改名删除，不给右键菜单。里面的小工具会自动关闭，见「设置」一节的「小工具自动关闭」。

### 快捷启动列表

- 只显示 `workspace_id` 为空的全局条目。
- 标题行右侧一个「＋」直接打开添加条目弹窗，没有添加菜单与排序开关。标题行高 32px，和工作区块的标题行一致。
- 主体为扁平列表（`LauncherList`，`role="listbox"` + `aria-activedescendant`，焦点常驻容器，↑↓/Home/End/Enter 导航，不依赖 GaN.UI Tree）；无分组，无拖拽。
- 行高 26px 单行，图标＋标题，target 走悬停提示。
- **图标**（`lib/kindIcon.tsx`，左栏、工作区工具栏、搜索候选共用）：取自文件树同一个 Material Icon Theme，两种来源：
  - **手选**：条目弹窗里的「图标」一行，点开「选择图标」子对话框（`IconPickerDialog`）：搜索框 + 全部可选图标的网格（915 个，不含浅色款和文件夹展开款），悬停看名字，点一个即选中，底部「恢复自动」。搜索匹配图标名，也匹配映射到它的扩展名 / 文件名 / 文件夹名（搜 `md` 找到 markdown；用「恰好等于」，免得冒出一大片）。选中的图标名存进 `items.icon`。
  - **自动**（没手选，`icon` 为空）：网页收藏 = `http`（地球），应用 = `exe`（窗口），终端命令 = `console`（终端），这三类各用固定一张；文件类按目标的文件名 / 扩展名匹配，目标是本机目录（`dirIds`）则按文件夹名匹配，和文件树里的同一项一致。目录判定结果回来之前，文件夹条目先按文件显示。
  - 库里的图标名图标包里没有时（旧版遗留、包升级删了）一律按自动显示；编辑弹窗也把它回填成「自动」，保存一次就清掉。
  - 浅色主题用专为浅底画的款式（手选的也一样：有 `<名>_light` 就换），所以左栏、工具栏、搜索框和条目弹窗都要传 `light`。
- **顺序固定**：网页收藏 → 应用 → 文件/文件夹 → 终端命令，同类型按标题升序（中文按拼音、忽略大小写）。规则只在 `lib/itemOrder.ts` 定义，侧栏与搜索候选共用，新增条目按规则归位而非追加末尾。
- **打开**：单击即启动（500ms 同条目防抖，吞掉连点与双击），回车同打开。网页收藏在当前工作区新开一块网页面板、不藏窗口，见「网页面板」。
- **右键菜单**：打开/编辑/移动到工作区/删除，目录条目另给「在此打开终端」，网页收藏另给「在系统浏览器中打开」（点后藏窗口）。无多选，改名一律走弹窗。

## 工作区工具栏

`WorkspaceToolbar`，放在顶栏里、工具集按钮左边，只在普通工作区渲染；临时工作区和断线态不渲染。

- **外观**：和搜索框同款的凹槽（`TitlebarWell`），高 28px、无分隔线；里面的按钮和条目高 24px。**不要用 `Scopebar`**：那是带边框的面板，放进顶栏会和凹槽搜索框两种材质打架。
- **位置与生长**：整体靠右、紧挨工具集按钮，宽度按内容算，条目多了往左长；顶栏空间不够时被挤窄（让位顺序见「窗口与顶栏」）。
- 条目是该工作区专属的快捷启动（`items.workspace_id` = 工作区 id），排序与左栏共用 `sortItems`，槽内顺序从左到右就是这个顺序。
- 最左边固定一个文件树按钮（工作区 folder 非空时显示），见下一节；再往右是固定的「打开当前文件夹」（同样只在 folder 非空时显示，不进 items 表）。它和文件树按钮一样只有图标、没有文字，悬停提示两行：「打开当前文件夹」和完整路径。
- 图标＋标题横向排列，「＋」固定右端，没有条目时只留「＋」。文件树按钮和「＋」不滚动。放不下时，「打开当前文件夹」加条目这一段在槽内横向滚动：**不显示滚动条**（28px 高放不下 10px 的滚动条），改用鼠标滚轮，纵向滚动量被换成横向。条目图标规则同上；固定的「打开当前文件夹」按钮用工作区文件夹名匹配的文件夹图标。
- 单击行为与左栏一致；右键菜单含打开/在此打开终端/在系统浏览器中打开（仅网页收藏）/编辑/移动到工作区/删除。

## 文件树

浏览当前工作区文件夹的只读浮层，业务封装 `FileTreePanel.tsx`，只给有文件夹的普通工作区；临时工作区没有入口。

- **入口**：顶栏工作区工具栏最左边的按钮，点一下弹出、再点一下收起，打开时显示按下态。没有快捷键，也不进搜索框和工具集菜单。
- **浮层**：GaN.UI `Sheet`，传 `modal={false}`——不加遮罩、不拦截下面的操作（停靠区里的终端和工具照常可点）。从左侧弹出，位置取自停靠区所在内容区的实际矩形（紧挨侧栏、从顶栏下沿到底），宽固定 320px，不可拖拽；右边线是 Sheet 自带的中性色，不染工作区色。样式细节待调。
- **收起**：点浮层外面、Esc、标题栏的关闭按钮、再点入口按钮、切换工作区、窗口被藏起来（失焦自动隐藏、热键或托盘收起）。窗口藏起来时浮层当场卸载、不播滑出动画：窗口藏着时动画不走，会拖到下次呼出才补播，表现为「再呼出时浮层还在、随即滑走」。靠主进程的 `hide` 事件经 `mp:window-hidden` 通知渲染端，不用页面的 `visibilitychange`——钉住时窗口被别的窗口完全盖住它也会报 hidden，那不是收起。「点外面收起」要放过入口按钮，否则点它关闭时会先收后开、闪一下。打开文件或目录后浮层不自动收起；窗口是否随之隐藏沿用 `openLocalPath`（未钉住时隐藏，与启动器一致）。
- **焦点**：树一挂载就聚焦（用回调 ref，不靠「数据读完」的状态：有预读时数据比浮层先就绪，而浮层内容经 Portal 晚一拍才挂上）；关闭后若焦点落回 body，就还给打开前的元素。Radix 的非模态对话框关闭时只还给触发器、不还给打开前的元素，所以这里自己还；点外面收起时焦点已在用户点的地方，不去抢。
- **标题栏**：左边文件夹名（悬停是完整路径），右边刷新和关闭两个图标按钮。
- **读目录**：`listDir(workspaceId, dir)` 每次只读一层，展开时才读。根目录由主进程按工作区 id 自己查，`dir` 必须等于或位于它之内，否则 `bad-request`；只做字面比较，不跟随符号链接，只为挡住界面传错参数，不是安全边界。目录没了回 `missing`，其余读失败（权限等）回 `failed`。主进程不排序不过滤，逻辑在 `server/fileTree.ts`。
- **显示**：目录在前、文件在后，各自按名称升序（中文按拼音、忽略大小写，规则同 `lib/itemOrder.ts`，实现在 `lib/fileTree.ts`）。**不隐藏任何文件**，`.git`、`node_modules` 也显示，不解析 `.gitignore`，没有「显示隐藏文件」开关。符号链接按目标类型显示：指向目录的当目录，坏链接当文件，不加标记。
- **图标**：Material Icon Theme，按完整文件名、扩展名（从最长的试起）、文件夹名匹配，匹配不上用默认图标，展开的文件夹换开口款，浅色主题用专为浅底画的款式（`lib/fileIcon.ts`）。图标 svg 不内联进 js（`?no-inline`），只有显示到的才被请求。面板整体懒加载，但 `lib/fileIcon.ts` 因快捷启动条目在首屏就要用图标，已随主包加载。
- **虚拟滚动**：不隐藏文件，展开 `node_modules` 这类目录一次有几千行，所以开虚拟滚动。上游 Tree 开虚拟滚动时把最大高度写死成 320px，调用处用 `max-h-none!` 盖掉，不改上游文件。
- **操作**：单击选中，双击或回车打开文件（目录是展开或收起，读完后是空的目录双击不做任何事）。右键菜单：打开、在文件管理器中显示、复制路径；目录再多「在此打开终端」。右键在行以外的地方不弹菜单。
- **展开状态**：本次运行内，每个工作区各记一份展开列表，切走再切回还在；关闭应用就丢，工作区改了文件夹则作废。
- **预读**：App 在空闲时先把面板挂上（没打开时什么都不画），代码包提前加载并执行完；面板趁此后台预读工作区文件夹的第一层，只存原始列表。第一次点开用预读结果立刻画出第一层，同时照常重读，内容有变化才替换，没变化不动（换节点会让树重新挂载，丢焦点和滚动位置）。有要还原的展开状态、或点刷新时不用预读结果，直接重读。预读失败不提示，点开时再读一次才报错。实测冷启动后首次点开约 335ms，预读加提前挂载后约 25ms；读目录本身只占约 10ms，大头是代码包。
- **刷新**：每次打开浮层、点刷新按钮、换主题时，把根和所有已展开的目录整棵重读。上游 Tree 把懒加载结果存在内部、没有刷新方法，浮层一关它就卸载，所以由面板自己拼出带 children 的节点，再换 `key` 让 Tree 重新挂载。读不到的展开目录（被删了、没权限）悄悄从展开列表去掉。不做文件监听。
- **出错与空**：工作区文件夹不存在或读不了，浮层里显示提示和「重试」「修改文件夹」两个按钮（后者走工作区右键菜单里已有的修改文件夹流程）；某个子目录读失败，该行显示 Tree 自带的「加载失败 + 重试」，不弹 toast；文件夹本身是空的，显示一行灰字。
- **不做**：树内搜索（找文件用 files 工具）、拖文件进终端或便签、新建/重命名/删除/移动文件、文件预览、文件监听、宽度拖拽、展开状态跨重启保存。

## 停靠区

GaN.UI `DockLayout`，业务封装 `DockZone.tsx`，底座 dockview-react。

### 实例与面板

- 每个工作区一套独立的 `DockLayout` 实例，同一时刻只显示当前工作区那套，其余留在 DOM 里以 `display:none` 隐藏（切换不结束任何终端进程，不丢 xterm 回滚缓冲）。
- 工具、终端会话和网页都是停靠面板，id 约定 `tool:<ToolId>`（单实例）、`term:<会话号>` 与 `web:<号>`（后两者多实例）。唯一性只在各自实例内成立，不同工作区出现同 id 不冲突。
- 激活权威是 dockview api：App 经 `whenDockApi` 命令桥开/关/激活，队列按工作区分开，桥在该工作区实例就绪前排队。
- dock 随首个面板打开懒加载并常驻。从未开过面板或面板清空时显示 `ToolHome`（前者在 dock 外直渲染，避免加载 dockview；后者作水印组件）。
- **新面板落哪一格**（`lib/dockLayout.ts` 的 `addPanelPreferEmptyGroup`，工具、终端、网页共用）：有空格子就优先填空格子，格子全有面板了就往第一格填。先后顺序是格子在页面上的顺序，左→右、上→下，所以恢复出来的一排空格子会被依次填满。**不看当前激活的是哪一格**，落点才好预测。最大化时走 dockview 默认（进激活格：其他格子是藏着的，进去就看不见），没有任何格子时也走默认（由它新建第一格）。已开的工具再点只是激活，不搬位置。
- **布局记忆**（`lib/dockLayout.ts`）：只记「格子怎么排」，不记里面开过什么。面板和终端仍然每次启动从空开始（用户决策，勿加还原）。
  - **记什么**：几列几行的嵌套关系、各格子的宽高、各格子的标签栏位置（上下左右）、最后激活的是哪一格。**不记**浮动窗口（变空会被自动清掉，没有格子可留）、最大化状态、固定标记。
  - **每个工作区各存一份**，临时工作区也存；新建的工作区从没有格子开始，删除工作区时清掉它的记录。
  - **存**：布局或激活格子一变就防抖（300ms）保存，不等退出时才存，托盘退出或被强杀时不一定来得及。最大化时跳过（`toJSON` 要先退出最大化，会引发反复保存）。一个格子都没有时删记录。存储位置见 `data.md`。
  - **还原**：该工作区的 dock 实例就绪时，在冲刷排队的开面板命令之前还原。还原出来的格子全是空的，显示「空白分组」；激活格子也还原，只决定启动时哪一格带高亮，不影响新面板落哪（见上一条）。窗口大小跟上次不同时按比例缩放。
  - **启动时的 dock**：记下的布局不止一个格子时，不等开面板就挂载 dock，让格子在启动时画出来（此时没有首页卡片，开工具走顶栏「工具集」或搜索框）；单格或没存过则保持懒加载。
  - **坏数据**：读不出来或还原失败，静默回到没有格子的默认状态，不弹提示。没有「重置布局」入口：想回到一格，关掉面板后点空白分组右上角的 ×，把空格子逐个关掉。
- **删除工作区时先逐个关闭该实例里的面板，再删数据行。** 反过来面板移除善后不触发，pty 会变成没人管的孤儿进程。

### 操作

- 拖标签自由分屏成组、浮动、最大化，带中文右键菜单。
- 批量关闭直接执行。终端面板关闭即结束 pty 并释放 xterm 实例；终端标签的 × 与中键关闭先弹确认，右键菜单关闭不确认。
- 组头不挂动作区：开工具走顶栏「工具集」菜单，关面板走标签上的 × 与标签右键菜单。

### 外观

- 停靠区四周没有描边，和侧栏的分界只靠底色深浅（侧栏 `--background`，停靠区 `--canvas`）。曾有过一圈工作区标识色的 1px 外描边，已去掉，别加回来。
- 活动标签朝外那侧的标识线在深色主题下也取同一颜色（main 上覆盖 `--dock-focus-top-line` / `--dock-focus-mark`），浅色主题保持原有的白色高光。
- 停靠区铺满工作区，不外套留白与细边框卡片。形状与层次归 dock 皮肤：组间距 `groupGap={4}`，缝色取 `--dock-gap`，组描边取 `--dock-group-border`。
- 深浅主题经 `DockLayout` 自带的 html 类监听自动跟随。

## 终端会话

- 终端工具入口 id 为 `terminal`（属于 ToolId），每个终端会话使用独立数字 id，开成独立 dock 面板（`term:<会话号>`）与其他工具并列。
- **工作目录**：
  - 终端工具在工作区里打开时取该工作区文件夹。
  - 工作区里的终端命令条目工作目录留空时同样继承工作区文件夹，显式填了就用填的。
  - 左侧命令条目留空仍走主目录。
  - 改工作区文件夹只影响之后新开的会话。
- **运行 ps1 脚本**：条目弹窗里类型选「终端命令」时，目标栏旁多一个「选择脚本…」按钮（仅 Windows），对话框只放行 `.ps1`，起始目录是所属工作区的文件夹（左侧条目或没有文件夹时用系统默认位置）。选中后一次填三处：
  - 命令栏：`pwsh -NoProfile -ExecutionPolicy Bypass -File "脚本路径"`；设置页查到本机没有 pwsh 就写成 `powershell`（Windows 自带的 5.1，读无 BOM 的 UTF-8 脚本会乱码，所以排在后面）。写成子进程调用而不是 `& 脚本`，是为了不管终端程序选 cmd 还是 PowerShell 都能跑，执行策略只对这一次放行。
  - 工作目录栏：脚本所在目录，**每次选都覆盖**（换脚本不留旧目录）；填完仍可手改。没走按钮、手敲的命令不自动带目录，仍按上面的规则。
  - 标题栏：为空时用脚本文件名（去扩展名）。
  - 命令照常敲进新开的终端面板，脚本跑完面板默认保留（shell 没退出），由用户自己关；想自动关见下一条「自动关闭」。「应用」「文件」类型和搜索框里的 `.ps1` 路径不变，仍用系统默认方式打开。
- **自动关闭**（仅终端命令，条目弹窗里的开关，默认关）：勾上后，命令**成功**结束就自动关掉那块终端面板；命令失败则面板保留，方便看报错。
  - **做法**：命令后面追加「成功才退出 shell」，PowerShell 是 `; if ($?) { exit }`，cmd 和各类 POSIX shell 是 ` && exit`。PowerShell 5.1 没有 `&&`，所以不能一律写它。
  - **追加什么由主进程给**：`ptySpawn` 的返回里带 `exitSuffix`（`pty.ts` 的 `exitOnSuccess`）。设置里选「自动」时实际用哪个 shell 只有主进程知道，渲染端不猜。命令仍由渲染端在 pty 起来后写入，没挪到主进程，免得改变写入时序。
  - **怎么关面板**：shell 一退出，`App.tsx` 里已有的 pty `exit` 事件处理就会 dispose xterm 并关面板，没有另外的关面板机制。
  - 弹窗里这一行只在类型为「终端命令」时显示，其他类型一律存 0；编辑时按存的值回填。已实测 PowerShell 7、Windows PowerShell 5.1、cmd 三种终端程序。macOS 的 zsh / bash 走 `&& exit`，未实测。
- **环境变量**：新建会话将 `TERM` 设为 `xterm-256color`、`COLORTERM` 设为 `truecolor`，并清除继承的 `NO_COLOR`，避免启动环境禁用彩色输出。
- **xterm 实例归 `termStore.ts`**，与面板生命周期解耦：面板拖动重组只重挂 DOM，不丢回滚缓冲；会话结束才 dispose；实例未就绪前的 pty 输出由它缓冲回放。
- 主题切换经 html 类监听热更新 xterm 配色，不重建进程，不清缓冲。

## 网页面板

点网页收藏、工具集里的「浏览器」都开成停靠面板 `web:<号>`，内容是一块 `<webview>`，组件 `components/WebPanel.tsx`（懒加载），创建在 `App.openWeb`。会话与安全在主进程 `src/main/webView.ts`。

- **开法**：每次都新开一块，不去找已开的（已开的那块可能早跳去别的页了）；开在当前激活工作区的停靠区，临时工作区也能开。标签名先取域名，页面标题到了跟着变；没有站点图标。关面板不确认，每次启动从空开始，不还原。
- **浏览器工具**：工具 id `browser`，中文「浏览器」，和终端一样没有 `Component`、可多开，每次新开一块空白页。空白页显示灰字提示，地址栏拿到焦点（等一帧再聚焦：从工具集菜单打开时，菜单关闭会把焦点还给它的按钮）；在地址栏输入网址后才创建 `<webview>`。排在 `TOOLS` 末尾，不进搜索框推荐区，只靠打字命中。
- **工具栏**：后退、前进、刷新（加载中变停止）、地址栏、「在系统浏览器打开」（点后藏窗口）。工具栏用 `Scopebar`（高 36px、`role="toolbar"`），**不要用 `Toolbar`**：`Toolbar` 自带 `gan-drag`（上游给窗口标题栏用的拖拽区），放在面板里地址栏和按钮点击到不了页面，鼠标是箭头，双击还会放大整个窗口；窗口失焦隐藏再呼出后焦点在搜索框，靠点击才能回到地址栏，所以表现为「地址栏输不进字」。`Scopebar` 是内容条、自带 `gan-no-drag`。加载中顶部一条细进度线（`Progress` 不定态）。页面跳转后地址栏跟着变，单页应用内部换页也跟；正在编辑地址栏时不被覆盖，失焦不回车则还原。**没有任何快捷键**，网页获得焦点后键盘全归网页。
- **地址栏规则**（`lib/webUrl.ts`）：不带 `://` 的补 `https://`；只放行 http/https；含空白、不是合法网址、或主机名是不含点号的单个词（`localhost` 和 IPv6 除外）一律提示「请输入网址」。**不做搜索**，没有搜索引擎。
- **加载失败**：内容区盖一块提示，写明失败的网址和 Chromium 的错误名，下面「重试」和「在系统浏览器打开」。失败的导航不触发 `did-navigate`，所以失败时要在 `did-fail-load` 里把地址同步成失败的网址。被新导航打断（`-3`）不算失败。
- **新窗口**：网页里的 `target=_blank` / `window.open`，http/https 在当前工作区新开一块网页面板，其他协议丢弃。`<webview>` 的新窗口不走主窗口的处理函数：主进程在 `web-contents-created` 里按类型给网页挂 `setWindowOpenHandler`，再经 `mp:web-open` 通知渲染端（preload 的 `onWebOpen`）。页面自己发起的跳转与重定向同样只放行 http/https。
- **窗口**：点开网页收藏后不再藏窗口（旧版是打开即藏）；未钉住时失焦自动隐藏的规矩不变，没有例外。
- **不重载的前提**：面板创建时带 `renderer: "always"`，内容画在 dockview 的覆盖层上，拖拽分屏、浮动时不被搬动。实测（真实鼠标拖标签分屏）网页元素还是同一个、没有重新加载；工作区实例被 `display:none` 隐藏再显示，页面状态也还在。不带这个选项，面板内容会被重新挂载，`<webview>` 会重载。
- **安全**（`webView.ts`，渲染端不碰这些）：
  - `will-attach-webview` 里钉死网页配置：不给 Node、不挂 preload、开沙箱和上下文隔离、分区强制为 `persist:web`（渲染端不传分区），初始地址只认 http/https 或空白页。
  - 权限一律拒绝，不弹询问（摄像头、麦克风、定位、通知等；请求和检查两个口都堵）。证书错误不放行，显示失败页，不给「继续访问」。
  - UA 去掉 `Electron/x` 与应用名，只留 Chrome 标准写法。**只设会话级不够**：实测 `<webview>` 的网页不吃 `session.setUserAgent`，请求头和 `navigator.userAgent` 都还带 Electron，所以每个网页的 `webContents` 创建时再各设一次。
  - 下载走 Electron 默认的「另存为」框，不做下载列表。这个框不经 `withNativeDialog`，所以在 `will-download` 里补了计数，框在场时不会被失焦自动隐藏。
- **登录态**：所有网页共用持久分区 `persist:web`，登录一次长期有效，不按工作区隔离，也不和图库的 `persist:gallery-import` 混用。数据在 `<数据目录>/browser-data/Partitions/web`，见 `data.md`「浏览器数据」。有些站（如 Google 登录）可能拒绝内嵌浏览器，不特意去绕，用「在系统浏览器打开」。
- **类型**：`@types/react` 把 `<webview>` 的 `allowpopups` 声明成布尔，而 React 要求传字符串，所以用 `createElement("webview", {...})` 而不是 JSX。
- **不做**：历史记录、页内查找、缩放、开发者工具、下载管理界面、网页内右键菜单、把当前页存成收藏、搜索引擎、搜索框里直接输网址、其他工具里的链接改走应用内。

## 设置

- **小工具自动关闭**（只管临时工作区；基础设置里的下拉，选项：关闭 / 5 / 10 / 30 / 60 分钟，默认 10 分钟，键 `scratchAutoClose`）：用户看不到临时工作区满这个时长，就把它停靠区里所有小工具面板（`tool:` 开头）一次全关。
  - **什么算「看不到」**：窗口藏起来了（失焦自动隐藏、热键或托盘收起），或窗口开着但当前在别的工作区，满足任一条就开始计时。窗口开着时只认主进程的 `hide` / `show` 事件（`mp:window-hidden` / `mp:window-shown`），钉住时被别的窗口盖住不算藏起来；钉住后最小化也不触发 `hide`，不计时，极少见，不处理。
  - **取消与重数**：窗口重新呼出且当前正是临时工作区，或窗口开着时切回临时工作区，计时取消；之后再离开从头数。计时中改了设置里的时长，按新时长从改动那一刻重新数；改成「关闭」立刻取消。
  - **关什么**：只关 `tool:` 面板（含「固定」过的），不动终端（`term:`）和网页（`web:`），不动格子排布，关完留下的空格子和手动关面板一样；普通工作区不受影响。
  - **不做例外**：到点全关，不判断工具忙不忙。便签没保存的草稿会丢，图库正在做的网址导入会被中止（关面板时会清暂存），AI 对话不受影响（会话在全局仓库里，历史保留、在途流继续）。
  - **没有提示**：关闭时不弹 toast、不留记录，设置项下方一行小字说明。
  - **实现**：计时在渲染端 `App.tsx`（各工作区的停靠区实例在那里），主进程只存取设置和发 `hide` / `show` 事件。启动时已开面板本来就是空的，所以计时不用跨重启。
- 分节内容随弹窗打开才挂载。剪贴板时限、翻译密钥、AI 模型由各分节挂载时自己读、提交时自己写，失败 `toast.error`，`App` 不持有它们。
- 界面主题、终端、字体和工具别名启动就要用，留在 `App`。
- AI 模型是 AI 工具和设置页共用的，放在共享 store `lib/aiModels.ts`：在设置里保存后，已打开的 AI 工具立刻生效，不用重开。
- **呼出热键的屏蔽名单**（只在 Windows 显示）：基础设置里「呼出热键」下方的多行文本框，一行一个程序文件名，失焦保存。名单里的程序在最前面时（典型是全屏游戏），双击修饰键和组合键都不呼出窗口，被拦时没有任何提示（提示会再盖到游戏上）。
  - 只拦「呼出」：窗口已显示时按热键照常收起；托盘点击、二次启动唤起不受影响（`app.ts` 里托盘走 `toggleWindow`，热键走 `toggleByHotkey`）。
  - 保存时整理成小写、补 `.exe`、去重，粘贴整条路径只留文件名；整理后的结果回填文本框。
  - 前台程序用 `koffi` 查（`server/foreground.ts`，Windows 专用）。查不到（`koffi` 不可用、受保护进程不让查）当作没命中，照常呼出，保证热键不会因一次查询失败而失灵。名单为空时不去查。

## 图库

- **网格**：整个网格只有一个右键菜单，点击和右键都在容器上按格子的 `data-index` 处理，空白处右键不弹菜单。格子是 `memo` 组件，勾选一张只重渲染那一格。没有上虚拟列表，真到上万张再上。
- **缩略图**：`mpimg://thumb/<id>` 回 404 时先显示占位，排队交给 Worker 生成（长边 320，不放大），同时最多 2 张，同一张只生成一次。存盘后带 `?v=1` 重新请求，绕开浏览器对失败结果的缓存。生成失败显示名字兜底块。
- **查看器**：删图只在本地移除这一张并刷新侧栏计数，不重置列表，也不滚回顶部。
- **从网址导入**：
  - 首页先探测一次 `content-type`（`galleryProbeUrl`），是图片就当单张候选。探测失败不算错，其余都走隐藏窗口渲染收集，没有静态解析。
  - 隐藏窗口翻页间复用，空闲 30 秒或会话清场（`galleryCollectReset`）时销毁，失败或超时后也销毁。
  - 每页总时限 15 秒，只等 `dom-ready`，到点就用已加载的 DOM 收集，所以图多的慢页面不算失败。
  - 首页渲染失败才报错；翻到后面的页失败时停止翻页，已收集到的候选照常呈现。
  - 抓取全部走抓取分区的 `session.fetch`，和隐藏窗口共用 cookie 与代理。`ProxyEnable=1` 时自动走系统代理；直连失败时读注册表 `ProxyServer` 试用一次，能通就固定下来，都不通就还原。超时覆盖到响应体读完，体积上限边读边判断。
  - `session.fetch` 的三个坑：`res.url` 恒为空串；https 的 referer 请求 http 目标时必须传 `referrerPolicy: "unsafe-url"`；`reader.cancel()` 不断开连接，提前结束要用 `AbortController.abort()`。
  - 隐藏窗口注入采集脚本要用 `mainFrame.executeJavaScript`，`webContents.executeJavaScript` 会等页面加载完。

## AI 助手

- 增量在 `aiSessions` 里攒 80ms 再提交。用定时器而不用 `requestAnimationFrame`：窗口藏到托盘时动画帧不触发。
- 消息行是 `memo` 组件，流式时只重渲染末条，历史消息不会重新解析 Markdown。
- 终结、停止、清空、重试、回滚、删专家之前都先写入积压的文字，保证不丢、不串。

## 便签

工具 id `notes`，中文「便签」，英文 `notes`。记项目里一闪而过的想法和临时数据，每个工作区一份（临时工作区也有），严格隔离：只显示当前工作区的便签，没有全部视图，搜索框搜不到便签内容。入口只有工具集菜单、工具首页和搜索框，没有工作区工具栏按钮和独立热键。

- **一条便签** = 一段文字 + 多张图片，可以只有其中一种，不能全空。文字原样显示（不渲染 Markdown），图片排在文字下方。
- **输入区**（顶部新建和条目编辑共用 `tools/notes/NoteInput.tsx`）：
  - 顶部新建的输入区单独成一条浅色横带，带底边线和轻阴影，与下方列表明显分隔；输入框本身比面板底色深，不加横带会和列表混在一起。
  - 从任何入口打开或重新激活面板时焦点进入输入框，高度随内容增长。
  - Ctrl+回车保存（macOS 上 Cmd+回车也行），回车换行；输入法选词时的按键不触发保存。保存后清空，焦点留在输入框；文字全是空白且没有图片时不保存。
  - 没保存的草稿（含图片）切工作区时还在，关面板就丢。
  - 加图三种方式：焦点在输入框时 Ctrl+V、把文件拖到面板任意位置、点按钮选文件（可多选）。保存前图片显示为小图，每张带 ×。
  - 拖到编辑中条目的输入区上，图片加到那一条；拖到别处加到顶部输入区。
  - 剪贴板文字非空时走默认粘贴（从 Excel、Word 复制只取文字）；否则取文件，非图片提示格式不支持。所有粘贴都 `stopPropagation`，否则 ScanTool 挂在 `window` 上的 paste 监听也会收到。
  - 粘贴、拖拽、选文件都统一成 `File`，保存时转成字节发给主进程。不用 `clipboard.readImage`：它会把所有图片转成 PNG，也拿不到复制的文件。
  - 支持 jpg、png、gif、webp、bmp，单张不超过 20MB，一条最多 20 张，单条文字不超过 10 万字；超出或格式不支持时 toast 提示。上限常量在 `tools/notes/limits.ts`，与主进程 `schemas.ts` 的 `NOTE_*` 手工保持一致。
- **搜索框带入**：选便签后回车，面板打开、内容进入输入框、焦点进入输入框，**不自动保存（用户决策，勿改）**；已有草稿时换行追加（其他工具仍覆盖）。
- **列表**：按创建时间倒序，每条依次显示时间（`11-05 14:32`）、文字、图片。不做置顶、标签、颜色。文字等宽、可选中，超过 10 行折叠可展开。图片限高 120px 显示原图（不生成缩略图），点击用系统默认程序打开，没有应用内查看器。
- **悬停按钮**：整条有复制文字（没有文字时不显示）、编辑、删除；每张图有复制图片（经 canvas 转 PNG，GIF 只得到静态图）。
- **编辑**：点编辑后这一条变成和顶部一样的输入区，能改文字、删图、加图。Ctrl+回车或保存按钮保存，Esc 取消，点别处不自动保存（点 × 或选文件都会让输入框失焦，容易误存），保存后位置不变，全空时不让保存。多条可以同时处于编辑状态。
- **删除**：整条立刻消失，不弹确认，toast 上 5 秒内可撤销。界面先隐藏，5 秒后才真正调 `noteDelete`；组件卸载（关面板）时立刻执行还没到时间的删除；应用在这 5 秒内退出时便签会留下，可以接受。不做一键清空，不自动过期。
- **删除工作区**：确认框写明「会同时删除 N 条便签」，便签与图片一起删。
- **不做**：工作区工具栏按钮、独立热键、搜索框粘贴图片、面板内查找、跨工作区移动、应用内看图、缩略图、图片去重。
