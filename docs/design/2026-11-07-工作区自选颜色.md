# 工作区自选颜色

## 目标

工作区的标识色现在是按 id 从调色板里自动取的，用户没法改。给普通工作区的右键菜单加一项「颜色」，从调色板里挑一个；挑过之后可以「恢复默认」回到自动取色。

## 方案

- **存储：`workspaces` 表新增 `color TEXT`（可空）。** 空 = 自动（沿用按 id 取调色板的规则），非空 = 用户选的 `#rrggbb`。老库用 `PRAGMA` 探测后 `ALTER` 补列，已有工作区全是空，颜色一个都不变。对外字段 `color: string | null`，写法同 `items.icon`。
- **存色值而不是调色板下标。** 以后调色板增删颜色，用户已经选好的颜色不会跟着变。
- **接口：新增 `setWorkspaceColor(id, color: string | null)`。** 传 `null` 就是恢复默认。主进程只校验格式（`#` 加 6 位十六进制），不认调色板（调色板只在渲染端）；临时工作区拒改，同改名一样返回 `bad-request`。
- **取色规则仍只在 `lib/workspaceColor.ts` 一处：** 临时工作区恒为中性灰，其余先看 `color`，空再按 id 取。侧栏竖色条、选中底色与描边、停靠区外描边三处本来就共用这个函数，不用逐个改。
- **界面：** 右键菜单在「重命名」「修改文件夹」之后加「颜色」子菜单，里面是调色板的色块（两排五个，当前颜色外圈描一圈；不打勾，因为浅色块上的白勾看不清）和「恢复默认」。调色板就用现有那十个，由 `workspaceColor.ts` 导出，不再另抄一份。

## 放弃的方案

- **自由取色（系统取色器、输入色值）：** 从右键菜单里弹原生取色窗口很别扭；任意色值在深浅两套主题下的底色与描边未必看得清，调色板里的十个是看过的。
- **存调色板下标：** 调色板一改，用户选的颜色就悄悄变了。
- **给临时工作区也开放改色：** 它的中性灰是用来和用户建的工作区区分开的，改了就失去这个作用，而且它本来就没有右键菜单。
