# 应用内浏览网页

## 目标

- 点网页收藏时，在应用内打开网页，可以和终端、工具并排放（左边看文档、右边跑命令），不再跳去系统浏览器。
- 工具集里新增「浏览器」，打开后是空白页加地址栏，用来临时看个网址。
- 所有 Chromium 的会话数据（缓存、cookie、`localStorage`、网页登录态）收进数据目录，不在系统里到处散落（用户明确要求，原话「我有强迫症」）。

## 方案

### 形态

- 每个网页是一块停靠面板 `web:<号>`，可多开，可分屏、浮动、最大化，复用现有停靠区。面板里只有一条工具栏，不做面板内多标签。
- 内嵌控件用 `<webview>`。它是普通页面元素，跟着停靠区的分屏、浮动、隐藏自动走，文件树浮层、右键菜单、弹窗、toast 都能盖在网页上面。
- 面板创建时带 `renderer: "always"`，内容画在 dockview 的覆盖层上，拖拽重组时不被搬动，网页不重载（实测）。
- 入口只有两个：点网页收藏、工具集里的「浏览器」。搜索框输网址、其他工具里的链接都不改走应用内。

### 行为

- 点网页收藏默认进应用内；右键菜单多一项「在系统浏览器中打开」，条目不加字段，settings 不加开关。
- 每次点都新开一块，开在当前激活工作区；关面板不确认；每次启动从空开始。
- 点开后不再藏窗口，未钉住时失焦自动隐藏的规矩不变。
- 网页里的新窗口：http/https 在当前工作区新开面板，其他协议丢弃。
- 地址栏只认网址（没写协议补 `https://`），不做搜索。
- 加载失败：面板内显示原因、「重试」、「在系统浏览器打开」。
- 没有任何快捷键；第一版不做历史、页内查找、缩放、开发者工具、下载管理、网页内右键菜单、收藏当前页。

### 安全与会话

- 所有网页共用持久分区 `persist:web`，不按工作区隔离，也不和图库的分区混用。
- 主进程在 `will-attach-webview` 里钉死配置：不给 Node、不挂 preload、开沙箱和上下文隔离、分区强制。权限一律拒绝，证书错误不放行。
- UA 去掉 `Electron` 与应用名。

### 数据目录

- ready 之前设 `app.setPath("sessionData", <数据目录>/browser-data)`，所有 Chromium 会话数据（含图库抓取的分区）都落进去。网页用普通的 `persist:web`，图库代码不用改。
- 缓存保留在里面，数据目录会随浏览变大，不提供清除入口。
- 指针和几个极小的 Chromium 文件（锁文件、`Local State`）只能留在默认根：应用要先读指针才知道数据目录在哪。
- 老用户首次启动新版时，把默认根里旧的 Chromium 文件一次性搬进 `browser-data`。
- 全新安装、旧名升级（这次启动才写指针）引导完成后重启一次，之后从第一帧起生效。
- 改数据目录时 `browser-data` 与 `chrome-profile` **重启后再搬**：指针里记 `moveFrom`，下次启动在 Chromium 起来之前搬。顺手修了已有缺口：`changeDataDir` 原来不复制 `chrome-profile` 还把旧的删了，改数据目录后受限站的登录态会丢。

## 放弃的方案及原因

| 方案 | 放弃原因 |
| --- | --- |
| `WebContentsView` | 原生层永远盖在页面元素上，文件树浮层、右键菜单、弹窗会被网页挡住；位置要靠主进程和渲染进程来回同步，代码量明显更大 |
| 只用 `session.fromPath` 搬网页和图库两个分区 | 主窗口自己的存储和缓存继续留在 `%APPDATA%\Knock\`，「到处拉屎」还剩一大半；要改写 `<webview>` 会话和图库的几处代码 |
| 改数据目录时当场复制 `browser-data` | 实测行不通：cookie 文件被会话独占（`EBUSY`），整目录复制报 `EACCES`，目录改名报 `EPERM` |
| 改数据目录前先关掉所有网页面板再搬 | 实测关掉所有 `<webview>`、刷盘、断开所有连接后，cookie 文件仍被占用：占着的是会话，不是网页，Electron 没有销毁会话的接口 |
| 不迁移，改目录后重新登录 | 登录态丢失，旧目录还留残渣 |
| 关掉网页缓存（`cache: false`） | 用户选了保留缓存，代价是数据目录会变大 |
| 内置搜索引擎 | 第一版范围外，不是网址就提示 |
| 按工作区隔离登录态 | 没有这个需求，多一份状态要管 |
| 把 `persist:gallery-import` 留在默认位置 | 用户要求「一起做掉」，用 `sessionData` 后自动完成 |

## 已知限制

- 有些站（如 Google 登录）可能拒绝内嵌浏览器，不特意绕，用「在系统浏览器打开」。
- 默认根里仍有指针、锁文件、`Local State`。
- `<webview>` 被 Electron 官方不推荐，但 42 里仍可用；Electron 锁在 42.x，升级前要重测拖拽不重载。
- 缓存在数据目录里，改数据目录时也一起搬，数据目录大时重启会慢一点。
