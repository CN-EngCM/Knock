# 砍掉工作区

## 目标

项目做偏了：工作区、停靠区（dockview）、文件树、应用内浏览器都是往「工作台」方向走的产物。这次回到「快速工具」：双击 Ctrl 呼出，左侧快捷启动列表 + 搜索框 + 内置工具，用完即走。

`工作台方向_dev` 分支保留着砍之前的完整代码，需要时去那里翻。

## 保留

- 左侧快捷启动列表（网页 / 应用 / 文件 / 终端命令，全局一份）、搜索框、双击 Ctrl、托盘、设置。
- 全部内置工具：json、qr、scan、files、translate、ai、gallery、notes、terminal。
- 侧栏拖宽与收成图标条。
- 页内终端（第一版就有，不属于工作区）。

## 砍掉

- 工作区（表、侧栏工作区块、顶栏工作区工具栏、增删改名改色弹窗、「移动到工作区」菜单、条目的所属工作区）。
- 停靠区：`dockview-react`、`ui/dock-layout`、`lib/dockLayout.ts`、`DockZone`。
- 文件树浮层，以及只有它用的 `ui/tree`、`ui/drag`、`@dnd-kit/core`。
- 应用内浏览器：`WebPanel`、`browser` 工具、`webView.ts` 的会话与安全。网页收藏回到系统浏览器打开并藏窗口。

## 方案

### 右侧区域：一排标签

回到 dockview 之前的样子：工具和终端会话是同一排标签里并列的页，按打开顺序排。

- 不能拖拽分屏、浮动、最大化，也不能拖动排序。
- 没显示的标签 `display:none` 保活，草稿和终端回滚不丢；关标签就是卸载，工具回初始态，终端会话结束。
- 一个标签都没有时显示 `ToolHome`。
- 除终端外每个工具只有一个标签，已开着再点只是切过去；终端每次点都新开一个会话。
- 终端标签：× 与中键关闭先弹确认，标题跟着 shell 的 OSC 标题走。不做右键改名与标签右键菜单（停靠区自带的，标签排没有）。

### 数据

启动时一次性、可重复跑的迁移（探测到旧结构才动手）：

- 重建 `items`、`notes`，去掉 `workspace_id`；专属条目和各工作区的便签全部留下，等于并进全局。
- 删 `workspaces` 表与 settings 的 `activeWorkspace` 键。
- 不备份（用户决策）。库升级本来就是单向的，`工作台方向_dev` 此后打不开这个库。

### 顺带的调整

- 素材注入、聚焦信号不再带工作区 id，按工具 id 投递。
- 搜索框候选收全部条目；便签全局一份。
- 终端工作目录：条目填了用填的，没填是主目录；文件夹条目右键「在此打开终端」保留。
- `webView.ts` 只留 `flushBrowserData`（改数据目录时刷盘用）。

## 放弃的方案

- **一次只开一个工具**：更简单，但切换就丢草稿，不要。
- **留着应用内浏览器**：它是跟工作区一波加的，没有停靠区就没处放，网页收藏用系统浏览器已经够。
- **留死表死列让两个分支共用一个库**：代码里会留一堆没人用的结构，不值得。
- **启动时清理旧的 `persist:web` 分区**：要写清理代码，只为几十 MB 缓存；`data.md` 里提一句手动删即可。
