## 验收方式

1. 全新状态：文件夹条目按 → 看到「在此打开终端 / opencode / Claude Code」，和改动前一样。
2. 设置 → 快速启动 → 文件夹动作：新增一个（名字「VS Code」、命令 `code .`、开自动关闭），回到搜索框按 → 能看到，执行后 VS Code 打开该文件夹、终端自己关掉。
3. 编辑、删除预置项，重新打开设置页仍是改后的样子；删光后子菜单只剩「在此打开终端」。
4. 名字 / 命令留空、命令带换行、超长、超过 10 个，弹窗里有提示且存不进去。
5. 终端标题显示为「动作名 · 文件夹名」。
