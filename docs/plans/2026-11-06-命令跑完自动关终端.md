## 验收

1. 新建终端命令条目，默认「自动关闭」是关的；类型换成网页 / 应用 / 文件时这一行不显示。
2. 开着自动关闭、命令成功（如 `echo ok`）：点条目后终端面板出现，命令跑完自己消失。
3. 开着自动关闭、命令失败（如 `cmd /c exit 3`）：面板留着，报错还在。
4. 没开自动关闭：面板留着，和以前一样。
5. PowerShell 7、Windows PowerShell 5.1、cmd 三种终端程序下 2、3 都成立。
6. 编辑条目时开关回填正确；老库升级后已有条目都是关。
