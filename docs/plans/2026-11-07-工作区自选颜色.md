## 验收

1. 普通工作区右键 → 颜色：弹出十个色块，当前颜色外圈有描边；选一个，侧栏竖色条、选中底色与描边、停靠区外描边立刻一起换成它。
2. 重启后颜色还在。
3. 「恢复默认」后回到按 id 自动取的颜色；没改过色的工作区「恢复默认」是灰的。
4. 临时工作区仍是灰色、仍没有右键菜单。
5. 老库升级后，已有工作区颜色都和升级前一样。
